Key Findings

  • UDS fastest: p50 0.03ms, up to 43,470 RPS
  • HTTP overhead: 200-300x slower than UDS (8-11ms vs 0.03ms)
  • gRPC balance: ~0.2ms p50, 6,500-8,200 RPS
  • Architecture: Flat/Layered/Hex within 10%
  • Language: Rust > C > Go for UDS

Recommendations

  • Ultra-low latency: Use UDS for local IPC
  • Cross-service: Use gRPC
  • Simplicity: Use HTTP when dev speed matters
